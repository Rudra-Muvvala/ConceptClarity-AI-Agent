# ConceptClarity — AI-Powered Learning Assistant

ConceptClarity is an AI-powered learning assistant designed to make complex concepts easier to understand through personalized explanations, interactive quizzes, visual diagrams, and study notes.

## ✨ Features

- **Multiple Teaching Styles:** Learn through analogies, step-by-step explanations, comparisons, stories, or balanced explanations.
- **Interactive Quizzes:** Test your understanding with quizzes generated by the AI.
- **Adaptive Re-teaching:** Get additional explanations when you answer a question incorrectly.
- **Visual Learning:** Generate Mermaid diagrams to help visualize concepts.
- **Downloadable Study Notes:** Export learning notes in HTML and Markdown formats.
- **Customizable Interface:** Use themes and an interactive Gradio interface.

## 🛠️ Tech Stack

- Python
- Gradio
- Google Gemini API
- Groq API
- Markdown processing
- Mermaid diagrams

## ⚙️ AI Providers

ConceptClarity uses Google Gemini as its primary AI provider, with Groq as a fallback provider.

The application requires API credentials to access the AI services. Configure the required API keys through environment variables or your hosting platform's secret-management settings.

- `GEMINI_API_KEY`
- `GROQ_API_KEY` (for the fallback provider)

**Security:** Never commit API keys, passwords, or `.env` files to a public repository.

## 🚀 Run Locally

1. Install Python.
2. Clone or download this repository.
3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your AI API keys as environment variables.
5. Start the application:

   ```bash
   python app.py
   ```

The Gradio interface will provide a local URL to open the application.

## ☁️ Deployment

This application can be deployed using a hosting platform that supports Gradio applications, such as Hugging Face Spaces.

Configure the required API keys as platform secrets before running the application.

## 🎯 Project Goal

The goal of ConceptClarity is to make learning more interactive and accessible by adapting explanations to different learning preferences and helping users check their understanding.
